# P07 · Condenser

**Use when:** A dissertation span must shrink (e.g., the 3,500-word theory
front-load → ~800 words; the Cabezón Cámara material → one sentence or a
footnote).
**Paste first:** [[Context_Bundle_Paste_First]].
**Then paste:** the span + the target word count.
**File output:** condensed version into [[Article_Master_Draft]]; original
stays untouched in `10_Context/`.

```
Condense this dissertation passage to [TARGET] words for the journal
article. Preserve, in order of priority: (1) the claim that serves the
article's thesis (animalization + coloniality + racialization), (2) any
primary-text evidence, (3) named theorists. Ruthlessly cut: defensive
hedges, historiographic throat-clearing, supplementary examples, and any
material belonging to the dissertation's other sections. Return the
condensed text plus a "cut list" naming each excised element and one
reason — so the author can rescue anything worth keeping as a footnote.

PASSAGE:
[paste]
```
