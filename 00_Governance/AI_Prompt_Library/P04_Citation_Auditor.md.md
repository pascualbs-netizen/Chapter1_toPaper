# P04 · Citation Auditor

**Use when:** Full-draft audit, and after any passage that introduces a
new secondary source.
**Paste first:** [[Context_Bundle_Paste_First]].
**Then paste:** the draft section + [[Works_Cited_Master]].
**File output:** corrections to [[Article_Master_Draft]] and
[[Works_Cited_Master]].

```
Audit this text for submission to HIOL.
1. MLA 9 compliance — in-text (Author Page) format; Works Cited entries
   against the master list I provide. Flag anything malformed.
2. Citation integrity — list every citation in the text and mark each
   ✅ in master list or ⚠️ VERIFY. Do not guess missing page numbers.
3. Multilingual rigor — every non-English term italicized on first use
   with a gloss; every Spanish quote followed by an English translation;
   diacritics correct.
4. Return a single table: issue | location | fix.

TEXT:
[paste]
```
