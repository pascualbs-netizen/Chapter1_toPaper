# Archive

Nothing in this vault is deleted. This folder holds:

- **Dated snapshots** of [[Article_Master_Draft]] before any major
  restructuring (`Article_Master_Draft_YYYY-MM-DD.md`)
- **Raw AI outputs** (drafts, critiques, condensation cut-lists) after
  their accepted content has been integrated into the workspace
- **A critique log** (`Critique_Log.md`) of rejected AI suggestions, so
  decisions are revisitable

If a file is here, it is history — the live versions are in
`00_Governance/`, `10_Context/`, and `20_Workspace/`.
