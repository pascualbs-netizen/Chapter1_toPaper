# Translation Glossary

> [!info] Protocol
> Italicize on first use + gloss in brackets. Subsequent uses stay
> italicized, no re-gloss. Enforced by [[P03_Translation_Enforcer]].

| Term | First-use treatment | Notes |
|---|---|---|
| *pichiciego* | *pichiciego* (a blind armadillo of the Argentine provinces, prized for burrowing — and, per the soldiers, for the grill) | pl. *pichiciegos*; dim. *pichi*/*pichis* |
| *pichicera* | *pichicera* (the pichis' underground burrow-refuge) | |
| *negro* | *negro* (in Argentina, a racialized class-slur for provincial, working-class, non-white populations — see Alberto & Elena) | NOT simply "black"; do not translate |
| *cabezas negras* | *cabezas negras* ("black heads," the historic term for the Peronist working-class multitudes of Oct 17, 1945) | originally a bird species name — the racialization was already an animalization |
| *quiltro* | *quiltro* (from Mapudungun; Chilean Spanish for a stray mongrel of indeterminate breed) | pl. *quiltros*; collective *quilterío* |
| *lumperío* | *lumperío* (the lumpen collective of the plaza) | |
| *Luminoso* | the *Luminoso* (the advertising light-beam that names and subjects the plaza's bodies) | keep definite article |
| *L'Iluminada* | L'Iluminada (the illuminated one) | |
| *pálidos* | the *pálidos* ("the pale ones," the crowd drawn from the shadows) | |
| *lumpérico animal* | the *lumpérico animal* (the cow-mare-thing of §3) | |
| *machi* | *machi* (Mapuche sacred healer) | paired as *machi/Mater* |
| *toqui* | *toqui* (Mapuche wartime chief) | |
| *ruca* | *ruca* (traditional Mapuche dwelling) | |
| *sarau* | — (not used in this article) | HIOL-model term only |
