# 📍 Article Workshop

> [!tip] How this vault works
> Obsidian is both the **governance layer** (rules, prompts, style, sources)
> and the **writing interface** (the draft lives here). The AI works for the
> vault — never the other way around. Every AI session is opened with the
> [[Context_Bundle_Paste_First]] and closed by filing the output.

## 🔁 The Working Loop

1. **Open a session** → paste [[Context_Bundle_Paste_First]] into the AI
2. **Pick a prompt** → from [[P00_System_Prompt|the Prompt Library]]
3. **Paste the context** the prompt asks for (from `10_Context/`)
4. **Work the output** → revise, then write in [[Article_Master_Draft]]
5. **Close the loop** → run [[P05_Governance_Check]], file results, tick progress below
